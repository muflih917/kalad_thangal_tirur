# Kalad Thangal Tirur - Medical Website

A modern, animated website for Dr. Kalad Thangal's clinic in Tirur, Kerala.

## Features
- 3D animated background (Three.js)
- Islamic-inspired design with geometric patterns
- Typing text animation
- Scroll reveal effects
- Interactive schedule with today highlighting
- FAQ accordion
- Contact form with validation simulation
- Fully responsive

## Folder Structure
- `index.html` - Main HTML file
- `css/` - Stylesheets
- `js/` - JavaScript files
- `assets/` - Images and fonts

## How to Use
1. Clone the repository.
2. Open `index.html` in a browser.
3. Customize content as needed.
